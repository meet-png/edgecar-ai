# Robustness: the blind questions as people type and say them

With the input repair (`edgecar.nlu.normalise`). The same run before the repair is in
[`robustness-no-repair/`](robustness-no-repair/robustness.md); the comparison is in [`repair.md`](repair.md).

Generated by `python -m edgecar.bench.robustness` (x86 laptop, 2 threads). Each cell: accuracy (95 % Wilson
interval) · questions lost / gained against the clean wording, with a paired exact McNemar p-value.
